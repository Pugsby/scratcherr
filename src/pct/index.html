Project Creation Tool

Scratcherrr is still in very early beta so I do not yet have a polished way of creating projects.
Because of this, I have made a very simple tool to create .scratcherr files. I recommend manually creating .scratcherr files though, since some features are neglected in the project creation tool.

Projects are stored in Scratcherr's data directory, ~/.config/scratcherr/ for UNIX and %APPDATA%/com.pugsb.scratcherr for windows
